# Wander Web Demo

这是一个为了参赛演示和网页体验而做的 `Web Demo` 版本。

它不是把原生微信小程序直接打包成网页，而是把当前最核心的产品体验重新整理成了一套浏览器里可直接体验的静态 Demo。

## 包含的核心流程

当前 Web Demo 覆盖了以下主链路：

1. 首页纸面桌面
2. 调焦
3. 多选观察纸条
4. 纸条折叠与纸飞机飞出
5. 首页状态记忆
6. 显影上传
7. 原图日记总结页
8. 可选“手绘显影”演示态

## 当前实现方式

这是一个纯前端静态 Demo：

- `index.html`
- `styles.css`
- `app.js`

不依赖构建工具，不依赖 npm 安装。

浏览器端使用：

- `localStorage` 保存 `active session`
- `localStorage` 保存草稿和最近日记
- 本地图片选择模拟上传
- 本地生成文案模拟 AI 输出

## 哪些是真实体验，哪些是 Demo 模拟

### 已经完整可体验

- 首页状态流转
- 调焦纸条选择
- 多选 1-3 张纸条
- 折叠与纸飞机动画
- 显影页上传图片
- 总结页查看原图、文字、问题、总结
- 保存到本地“最近散步”

### 当前是 Demo 模拟

- AI 解读
- 反思问题
- 一句日记总结
- 手绘显影

这些内容目前是在浏览器里做的本地模拟，目的是让评审或体验者可以完整走完产品节奏，而不依赖微信小程序环境和云函数权限。

## 本地打开方式

### 方式一：直接双击

直接打开：

- `web-demo/index.html`

大多数情况下就可以直接体验。

### 方式二：本地静态服务器

在项目根目录运行：

```bash
python3 -m http.server 8080
```

然后打开：

- [http://localhost:8080/web-demo/](http://localhost:8080/web-demo/)

这种方式更稳定，尤其是图片、本地缓存和页面跳转体验会更接近真实访问。

## 推荐对外托管方式

如果你想给评审一个网页链接，推荐这些静态托管方式：

- GitHub Pages
- Vercel
- Netlify

因为这个 Demo 是纯静态文件，所以部署非常轻。
